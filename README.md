## 🎯 Цель работы

Изучить нормализацию реляционной БД до 3NF на примере таблицы заказов с классификацией товаров, устранить аномалии обновления, удаления и вставки, соблюсти условия: один код заказа соответствует только одному клиенту, товары классифицируются по коду товарной классификации.

---

## 📋 Задачи

1. Создать БД `orders_norm` и таблицу `orders_unnormalized`
2. Продемонстрировать три аномалии
3. Привести данные к 3NF — 5 таблиц (`customers`, `categories`, `products`, `orders`, `order_items`)
4. Перенести данные через `INSERT ... SELECT DISTINCT`
5. Проверить целостность (сумма 303 000.00)
6. Сделать дампы до и после нормализации
7. Настроить логирование и экспортировать отфильтрованный лог

## 🚀 Запуск

```bash
mkdir ~/lab5_normalization && cd ~/lab5_normalization
# Создать my.cnf, затем:
docker run --name shop_norm \
  -e MYSQL_ROOT_PASSWORD=123 \
  -e LANG=C.UTF-8 \
  -e MYSQL_INITDB_SKIP_TZINFO=1 \
  -v mysql_data:/var/lib/mysql \
  -v $(pwd)/my.cnf:/etc/mysql/conf.d/my.cnf \
  -d mysql:8.0
```
